**Живая версия:** https://baibakova2005-art.github.io/uhod-za-kozhey/

## Стек

React 19, Vite 8, Tailwind CSS 4. Шрифты Unbounded и Manrope подключены локально через Fontsource.

Где что лежит:

- `src/data.js` — все тексты, товары, цены, вопросы, фото;
- `src/App.jsx` — порядок блоков страницы;
- `src/ui.jsx` — шапка, секция, вопросы, форма, подвал (основа из demo-manikyur);
- `src/Bottles.jsx` — нарисованные флаконы;
- `public/privacy|consent|terms/` — документы для формы.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://127.0.0.1:5195/uhod-za-kozhey/` (порт 5190 занят demo-manikyur).

Сборка: `npm run build`, готовый сайт — в папке `dist`.
